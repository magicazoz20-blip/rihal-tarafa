# رِحال | عالم طرفة بن العبد

تجربة أدبية تفاعلية باللغة العربية للتعرّف إلى طرفة بن العبد والعصر الجاهلي والشعر والمعلقات.

## المحتوى

- ست محطات قراءة مستقلة عن الشاعر والسياق والشعر الجاهلي والمعلقات ومعلقة طرفة وخصائصه الفنية.
- خمس ألعاب قصيرة: أسئلة متعددة الخيارات، صح أم خطأ، إكمال العبارة، التعرّف إلى صاحب المعلقة، ومطابقة المصطلحات.
- نقاط ومستويات وإنجازات وملف شخصي؛ يُحفظ التقدم محلياً في المتصفح.
- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.

## التشغيل

افتح `index.html` في متصفح حديث. لا يحتاج المشروع إلى تثبيت حزم أو إعداد خادم.

## النشر

ينشر GitHub Actions الموقع إلى GitHub Pages عند كل تحديث لفرع `main`.

## المراجع الأدبية

- طرفة بن العبد، *الديوان*، شرح الأعلم الشنتمري، تحقيق درية الخطيب ولطفي الصقال، مجمع اللغة العربية بدمشق.
- أنور أبو سويلم، «قراءة في معلقة طرفة بن العبد»، مجلة العلوم، دار جامعة الملك سعود للنشر.
- *موسوعة تاريخ الأدب العربي*، مؤسسة هنداوي.

تُنبه الدروس إلى اختلاف الروايات القديمة، ولا تعرض الروايات المختلف فيها عن المعلقات بوصفها حقائق محسومة.
